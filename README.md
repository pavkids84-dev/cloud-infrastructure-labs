# Cloud Infrastructure Labs

This repository documents my hands-on learning journey in cloud infrastructure engineering.

The focus is on building strong fundamentals through practical labs, system inspection, troubleshooting, automation, and technical documentation rather than only memorizing commands.

- File and directory management

- Environment variables

- Shell scripting
- Text processing with `grep`, `sed`, and `awk`
- Archive and compression
- Process management

- Package management
- Shell variables and parameter expansion
- Command-line arguments
- Conditional logic
- Loop control
- Bash functions
- Linux troubleshooting fundamentals

## Learning Approach

Each topic is approached through a practical workflow.

```text
Concept
   |
   v
Hands-on Practice
   |
   v
Verification
   |
   v
Interpretation
   |
   v
Troubleshooting
   |
   v
Documentation
```

The goal is to understand not only how to execute a command, but also:

- Why the command is used
- What happens inside the system
- How to verify the result
- How different Linux components are connected
- How to investigate failures
- How to document the work clearly

## Troubleshooting Mindset

Troubleshooting records follow a structured process.

```text
Problem
   |
   v
Investigation
   |
   v
Evidence
   |
   v
Root Cause
   |
   v
Resolution
   |
   v
Verification
   |
   v
Lesson Learned
```

The objective is not simply to fix a problem, but to understand why it happened and how the system behaved.
